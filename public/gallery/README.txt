Put job photos in this folder.

  1. Drop the image here, e.g.  mustang.jpg
  2. Open  src/data/gallery.ts  and set  src: '/gallery/mustang.jpg'
     on the entry you want it to fill.

Tips: landscape shots look best, 1600px wide is plenty, and keeping each
file under ~400KB keeps the site fast (squoosh.app compresses for free).
